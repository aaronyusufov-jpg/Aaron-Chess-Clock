
# ♟ Aaron Chess Clock

A modern chess clock designed by Aaron.

## Features

- Clean, professional dark interface
- Multiple time controls:
  - 3 minutes
  - 5 minutes
  - 5 minutes + 3 seconds
  - 10 minutes
  - 15 minutes + 10 seconds
  - 30 minutes
- Custom time and increment settings
- Sound effects
- Vibration support on compatible devices
- Pause, resume, reset, and flip controls
- Progressive Web App support
- Offline caching after the first successful visit

## Files

- `index.html` — application structure
- `style.css` — interface and design
- `app.js` — chess clock logic
- `manifest.json` — app installation settings
- `sw.js` — offline caching
- `icon.svg` — application icon

## Run locally

Open `index.html` in a browser, or publish the repository using GitHub Pages.

## Publish with GitHub Pages

1. Open repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`.
5. Press **Save**.

Wait for the published website link to appear in the Pages section.

## Install on iPhone

1. Open the published website in Safari.
2. Tap **Share**.
3. Select **Add to Home Screen**.
4. Tap **Add**.
